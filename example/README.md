# AgeWallet iOS Demo

Example iOS app demonstrating the AgeWallet SDK.

## Setup

1. Open `AgeWalletDemo.xcodeproj` in Xcode
2. Update the `clientId` in `ContentView.swift` with your AgeWallet client ID
3. Set your development team in the project settings
4. Build and run

## Bundle ID

`io.agewallet.sdk.demo.ios`

## Universal Links

The app is configured to handle Universal Links from:
- `https://agewallet-sdk-demo.netlify.app/callback`

Make sure your Apple Developer account has the Associated Domains capability enabled.
